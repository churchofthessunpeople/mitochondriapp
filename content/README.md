# Content overlays

Git-tracked Admin edits for activities, how-to, articles, categories, and labels.

- Written by **Admin → Content** when running locally (`npm run dev`)
- Merged over TypeScript baselines at runtime
- Commit and deploy these files for production — Neon is not the catalog CMS
